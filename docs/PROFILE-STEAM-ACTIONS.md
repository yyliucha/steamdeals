# 个人资料 Steam 账号操作补全（FE，待开发，2026-11-23）

> 所有者反馈（2026-11-23，v2.28.7 EZ 发布后）：
> 1) Steam 账号 Tab **没有「同步 Steam 愿望单 / 库存」按钮**——普通用户也要可以用；
> 2) 该页四个按钮（查看已拥有/查看愿望单/设为默认/解绑）**是原生样式**，要改成站内样式。

## 1. 现状（代码证据）

| 项 | 事实 | 位置 |
|---|---|---|
| 同步接口 | `POST /api/steam/accounts/:id/library/sync`、`/wishlist/sync`——权限 `requireUser` + `requireAccountOwner`（**普通用户本人可用**，需账号 API Key）；EM 已实现异步（202+`GET .../sync-status`） | `src/routes/site.js` accountAction 分支 |
| 个人资料 UI | EZ 的 Steam 账号 Tab 只有：查看已拥有/查看愿望单/设为默认/解绑 + 绑定新账号——**没有同步按钮** | `frontend/src/pages/ProfilePage.vue`（Steam 账号 Tab） |
| 按钮样式 | 模板用的是 `el-button`，但线上截图显示为原生按钮 → 需排查（样式被覆盖/未生效/构建问题） | `ProfilePage.vue` |

## 2. 需求

1. **Steam 账号 Tab 每个账号增加「同步游戏库」「同步愿望单」按钮**：
   - 普通用户本人可用（调用上述接口；账号无 API Key 时提示「该账号缺少 API Key，请先配置」）；
   - 点击后按钮进入「同步中…」（禁用），轮询 `GET /api/steam/accounts/:id/sync-status`（2s，最长 60s），完成后刷新账号统计并提示结果；
   - 与「查看已拥有/查看愿望单」并列，放在账号操作区；
2. **按钮样式**：该页所有按钮统一使用站内 Element Plus 样式（`el-button` 正确渲染，圆角/品牌色/危险色），**不得出现浏览器原生按钮**；
   - 排查现有按钮是否为原生（检查样式覆盖/全局 reset/构建产物），修复后以普通用户身份截图确认；
3. 手机端同样提供同步按钮（紧凑布局：2×N 按钮组）。

## 3. 验收

1. 普通用户：账号卡片出现「同步游戏库/同步愿望单」，点击 → 同步中 → 完成后统计更新（无 15s 超时）；
2. 无 API Key 的账号点击 → 明确提示（不报 500）；
3. 页面所有按钮为 el-button 样式（无原生按钮）；截图对照（桌面 + 手机端）；
4. 同步接口权限不变（普通用户本人可用；他人账号 404/403）；
5. `npm test`（分段）+ `frontend:build` + `scan` 全绿。
