安全约束与验收断言

眼睛切换不能牺牲安全：明文懒加载、审计可追溯、自动回密文。

安全约束（逐条实现）

项做法
权限仅管理员；后端只允许 secret 字段
懒加载页面加载不取明文；点眼睛才调一次接口
审计每次显示明文写 audit_logs（admin.secret_revealed，只记 key 名）
自动回密文30 秒无操作自动切回 type=password
不误覆盖未改动不提交；留空 = 保持原值
不进存储明文不进 localStorage / 前端日志 / URL
复制选中复制；Clipboard API 可用时给「复制」按钮
不批量不做「全部显示」，一次一个 key

demo 状态 ↔ 自动化断言

状态断言点预期
① 密文已配置渲染type=password + 眼睛存在
② 明文点眼睛调 value 接口一次，type=text 显示明文
② 再点点眼睛回 type=password，不重复调接口
③ 未配置无值眼睛置灰不可点，无接口调用
④ 编辑改值保存只提交改动项；未改动不提交
⑤ 清除点清除二次确认 → 保存 null，回落 env/默认
审计显示明文后查库audit_logs 新增 admin.secret_revealed
自动回密文30 秒后type 回到 password
