安全约束（实现必须逐条满足）

项做法
权限仅管理员（沿用已有 requireAdmin + 后端只允许 secret 字段）
审计每次查看落 audit_logs（admin.secret_revealed：key / 管理员 / IP / UA），不含值
明文生命周期只在弹窗内存；关闭或 30 秒倒计时即清；不进表单 / localStorage / 前端日志
掩码固定 12 点，不透露真实长度
复制Clipboard API；HTTP 环境降级为「已选中，Ctrl+C」提示
批量不做「全部显示」；一次一个 key（后端也是单 key 接口）

6. demo 状态 ↔ 自动化断言对照表

demo 状态断言点预期
A 未配置卡片分支渲染显示「尚未设置」+ 设置按钮，无「查看」
B 已配置掩码与动作输入框值为 12 个点；「查看 / 编辑 / 清除」三按钮同时存在（四种布局分支都有）
C 确认弹窗点击「查看」先弹确认框，文案含「审计日志」；取消不发请求
D 明文态确认后调用GET /api/admin/settings/value?key= 一次；明文等宽显示 + 复制按钮 + 倒计时
D 关闭/超时30 秒或点关闭明文清空、DOM 中不再存在该值
编辑弹窗点「编辑」输入框为空（不回显旧值），留空保存不发 PATCH
清除点「清除」二次确认 → 保存 null；来源回落为 env/默认
移动端 375px布局三动作换行、输入框不溢出、无横向滚动
权限非管理员请求401/403，接口不返回明文
审计查看后查库audit_logs 新增一条，action=admin.secret_revealed，只含 key 名
