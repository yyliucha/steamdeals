## 质检中发现并已处理的偏差

1. **计数查询 42P18**：`listVisitorLogs` 加 `days` 参数后，count 查询传了未被引用的 `$3/$4`，Postgres 无法推断类型；
   已改为 count 查询只传 3 个参数（时间窗占位符换成 `$3`），`visitors.test.js` 回归全绿。
2. **展开行无样式**：IP 展开行初版没有 CSS，已补 `.ip-detail/.log-line` 样式（`f109f83`）。
3. **测试自身健壮性**：登录/管理请求会被访问日志中间件写成 127.0.0.1 行，影响统计断言；测试内先删除该 IP 行，
   并把明细视图的 `days` 时间窗行为补进断言（`f109f83`）。

## 风险提醒（不判错）

1. 黑名单支持 CIDR（如 `1.2.3.0/24`），但「已封禁」状态与统计列按 **IP 等值**匹配；网段条目的统计/状态为 0/正常。
   现状黑名单以单 IP 为主；若将来常用 CIDR 再补 `<<=` 匹配（本批不做，规格 §3.4 同口径）。
2. IP 数值序用「补零字符串」实现 IPv4 数值序，IPv6 退化为字典序（注释已说明）；访问日志目前以 IPv4 为主。
3. 统计为实时聚合（带时间窗条件走现有索引），数据量增长后的物化视图优化在「本批不做」清单内。
