# 系统设置信息架构重构（平台卡片 + 常用/高级折叠 + 只看非默认）（待开发）

> 状态：**已确认待开发（2026-11-17；demo 已确认：[design/settings-ia-2026-11-17-v2.html](design/settings-ia-2026-11-17-v2.html)）**。
> 关联：[TODO.md](TODO.md) CQ 条目、[WEB.md](WEB.md)（后台页面与 API）、[ADMIN-CONSOLE-IA.md](ADMIN-CONSOLE-IA.md)（AT 批设置页 tab 化先例）。

## 1. 现状与痛点（2026-11-17 实测）

- `src/settings.js` 共 **86 个 `def()`**，分 7 组：sources **32**、advanced **16**、alerts 13、security 10、site 8、auth 4、network 3；
- 「数据源与采集」32 项平铺：开关、间隔、条数、限速、Key 混在一起，看不出"哪个平台没开/多久跑一次"；
- 「高级」16 项一屏到底；「站点与内容」8 项里权重类与常用项混排；
- 每次新增设置项都继续平铺，页面越来越长、越来越难维护。

## 2. 已确认的决策（demo v2 已确认）

| # | 决策 |
|---|---|
| 1 | **数据源与采集按平台卡片化**：全局 / Steam / 杉果 / ITAD / **GOG+Humble 合一卡** / 发现与热度；卡头 = 图标 + 名称 + 启用状态 + 开关。 |
| 2 | 每张卡**常用区 ≤3 项**，其余收进「**高级 N 项 ▸**」折叠（**默认收起**）；折叠标题行显示关键值摘要（如 `热点阈值 1 · 冷门 3 天 · 状态判定 6000/1500ms/600s`）。 |
| 3 | 「站点与内容」：常用 = 成人内容展示 / 站点公开地址 / 手机跳转 / 时区；权重类收进「**推荐与评分 4 项**」折叠。 |
| 4 | 「高级」16 项拆 **4 个折叠组**：调度与熔断 / 备份与日志 / 缓存与图片 / 时区与显示（默认收起，标题行带摘要）。 |
| 5 | 通用能力：**只看非默认**（顶部开关，localStorage 记忆）、**来源标注**（数据库 / 环境变量 / 默认）、**恢复默认**（单行 + 分组）、**搜索命中折叠项自动展开并高亮**。 |
| 6 | 实现方式：**不改任何设置 key / 默认值 / 语义**；在 `settings.js` 的 `def()` 增加 meta（`section`、`tier: 'primary'\|'advanced'`、`summary`），`/api/admin/settings` 下发 schema 带 meta，前端按 meta 渲染。新增设置项自动归位，无需改前端顺序。 |
| 7 | 保存 / 重新加载 / 修订号 / 15 秒热加载行为不变（仅新增"只看非默认"过滤与折叠展示）。 |

## 3. 改动落点

- `src/settings.js`：`def()` 支持 meta（section/tier/summary），给 86 项补齐分组与层级（**不改 key/默认值/env**）。
- `src/settings-routes.js` / `src/server.js`（settings schema 接口）：下发 meta + `source`（`db|env|default`）与 `isDefault`（当前值是否等于默认）。
- `frontend/src/pages/AdminModules.vue`（设置区）：按 meta 渲染平台卡片 / 折叠组；顶部「只看非默认」；行级「恢复默认」+ 分组级恢复；搜索命中折叠内项时自动展开并高亮；折叠状态存 localStorage。
- `test/settings.test.js` 扩展：meta 完整性（每个 def 都有 section/tier）、恢复默认语义、只看非默认过滤纯函数。

## 4. 验收（与 demo 逐项对应）

| demo 状态 | 断言点 | 预期 |
|---|---|---|
| 数据源 tab | 平台卡数量与分组 | 出现 6 张卡（全局/Steam/杉果/ITAD/GOG+Humble/发现与热度），每卡常用 ≤3 项 |
| 折叠 | 默认状态 | 高级折叠默认收起；标题行显示摘要关键值 |
| 站点与内容 | 常用 + 折叠 | 常用 4 项；「推荐与评分 4 项」折叠存在且收起 |
| 高级 tab | 折叠组 | 4 个分组存在、默认收起、展开显示对应项 |
| 只看非默认 | 开关 | 打开后只显示非默认项；刷新页面后保持；关闭恢复全部 |
| 来源标注 | 徽标 | 数据库 / 环境变量 / 默认 三类正确显示（DB 覆盖 env 时显示"数据库"） |
| 恢复默认 | 单行 + 分组 | 单行恢复后值=默认、来源变"默认"；分组恢复一次性生效（有二次确认） |
| 搜索 | 命中折叠项 | 自动展开并高亮该行；无命中显示空态 |
| 行为不变 | 保存 / 重新加载 | 修订号递增、15 秒热加载、401/403 行为不变 |
| 通用 | `npm test` / `frontend:build` / `scan` | 全绿；移动端卡片单列、折叠保留 |
