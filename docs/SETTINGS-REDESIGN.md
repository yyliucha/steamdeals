## 0. 背景与现状（2026-11-27 核实 + 所有者截图）

| 项 | 现状 |
|---|---|
| 设置项 | **94 项**（数据源与采集 33 / 站点与内容 14 / 账号与登录 4 / 安全与限流 11 / 通知与提醒 8 / 网络与代理 7 / 高级 17） |
| 结构 | 横向 7 tab → 组内平台卡片 → 卡内「高级 N 项」折叠 = **3 层** |

## 3. 前端

### 3.1 路由

| 地址 | 行为 |
|---|---|
| `/console/settings/sources` | 数据源（默认页；`/console` 重定向到这里） |
| `/console/settings/:group` | 7 组之一；未知 group → 回落 `sources` |
| `/console/settings/:group?q=xxx` | 带搜索词进组（可分享） |

实现：`router/index.js` 加 `/console/settings/:group?`；`Console.vue` 读 `route.params.group` 渲染对应组；左导航点击 `router.push`。

### 3.2 布局

- 左导航（236px）：7 组（图标 + 名称 + 项数徽标），当前组高亮 + 左侧品牌色条；底部版本 / 修订 / 「改一项即存，约 15 秒生效」；
- 右侧：面包屑（管理控制台 / 系统设置 / 当前组）→ 组标题 + 描述 → 工具栏（搜索 + 只看非默认）→ 分区列表；
- 每个分区 = 分区标题（名称 + 项数 + 启用状态徽标）+ 一行一项；
- 每行：左「label + 帮注 + hover 才出的来源/恢复默认」，右「控件 + 保存状态」。

### 3.3 即时保存

- bool / enum：`change` 立即发；int：输入防抖 **600ms**，`blur` 立即发；
- **连续改动合并**：1.5 秒窗口内多次改动合并成一次 `POST /api/admin/settings {values:{...}}`，避免 revision 狂涨导致调度器反复水合；
- 行内状态：`保存中…`（spinner）→ `✓ 已保存`（2 秒后淡出）；失败 → 回滚上次值 + 红字「✕ 原因」；
- 移除全局「保存设置」按钮；页面离开时若有未发出的改动，强制 flush 一次。

### 3.4 搜索与过滤

- 搜索常驻当前组顶部，**跨 7 组**匹配（label / key / help）；命中结果面板显示「组 · 项」，点击跳组并高亮；
- 只看非默认：沿用 localStorage 记忆；打开后只显示非默认项（含高级项）。

### 3.5 移动端

- ≤560px：左导航 → 顶部「<组名> · N 项 ▾」下拉；每行改上下两段（label 在上、控件占满宽、保存状态在控件下）；
- 触摸目标 ≥44px。

**demo**：[design/settings-redesign-2026-11-27.html](design/settings-redesign-2026-11-27.html)（`?shot=1/2/3`），
验收必须「与 demo 一致」。

## 4. 后端

- **无接口变化**：仍用 `GET /api/admin/settings`（schema）与 `POST /api/admin/settings`（`values` 局部保存）；
- 单 key 保存已支持（`settings.saveSettings` 增量写 + revision +1 + 水合）；
- 需确认「连续保存的合并」只在前端做，后端无需节流。

## 5. 设置与配置

- 无新增设置项、无默认值变化、无迁移；
- 仅调整 `GROUPS` 与 meta 的展示归属（分组 id 变化：`auth`+`security` → `access`，`advanced` → `schedule` + `ops`），
  需同步 `SETTINGS_SECTIONS`、`PLAIN_GROUPS` 与前端引用，**并加一条迁移断言测试**（所有 key 都能落到新组，不丢项）。

## 6. 安全

- 权限不变（`requireAdmin`）；
- 密钥字段沿用 FX 的懒加载 + 审计 + 30 秒回密文；
- 即时保存不改变服务端校验（越界/非法值仍返回 400 并回滚）。

## 7. 验收（8 条）

1. 左导航 7 组（新名称与项数）；点击换 URL（`/console/settings/<group>`），**浏览器后退可回上一组**；
2. `/console/settings/sources` 直达；未知组回落 `sources`；`/console` 重定向到 `sources`；
3. 右侧布局为「分区标题 + 一行一项」——**页面上不再有卡片盒子与「高级 N 项 ▸」折叠**（静态锁）；
4. 即时保存：toggle / select 改动后 1 秒内出现 `✓ 已保存`；int 输入停止 600ms 后保存；失败回滚原值并标红；
5. 连续改 3 项（1.5 秒内）只发 **1 次** `POST /api/admin/settings`（断言请求次数）；
6. 来源徽标与「恢复默认」默认不可见，**hover/focus 该行才出现**；
7. 搜索跨 7 组命中并可跳组；「只看非默认」过滤生效且刷新后仍生效；
8. 移动端 375px 左导航变顶部下拉、控件占满宽、无横向溢出；`npm test`（分段）+ `frontend:build` + `scan` 全绿。
