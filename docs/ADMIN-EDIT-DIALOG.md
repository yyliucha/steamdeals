# 后台「添加/编辑」统一弹窗（EK，待开发，2026-11-20）

> 所有者要求（2026-11-20）：后台的添加/编辑操作**全部用弹窗**，不要内联表单/抽屉。
> 范围排查（代码证据 2026-11-20）：frontend/src 全量 grep `el-dialog|el-drawer|inline-form`。

## 1. 已是弹窗（无需改）

编辑游戏/合并游戏/封禁设备/迁移提醒/推送提醒/删除用户/临时密码/API Key/模板预览与测试/
确认对齐/批量确认/批量忽略/手动指定目标/批量操作详情/游戏详情/未保存确认等。

## 2. 需要改（本条目范围）

| # | 位置（文件） | 现状 | 改为 |
|---|---|---|---|
| EK-1 | AdminModules.vue 安全与限流 → IP 黑名单添加 | `inline-form` 内联 | 按钮「添加黑名单」→ 弹窗（IP/备注/确认） |
| EK-2 | AdminModules.vue 安全与限流 → IP 白名单添加 | `inline-form` 内联 | 按钮「添加白名单」→ 弹窗（IP/备注/确认） |

| EK-5 | 系统设置 → 通用出网代理 / App 同步专用代理 | 内联输入框 | 「编辑」按钮 → 弹窗（掩码显示、校验 http/https） |

## 3. 明确保留（不算添加/编辑）

- 搜索栏 `inline-form`（愿望单/到价提醒搜索）——筛选输入，不弹窗；
- 审阅记录抽屉（AlignAdmin `history`，只读查看）、游戏链接抽屉（GameLinksDrawer，只读查看）；
- 前台页面所有弹窗/抽屉（不在后台范围）；
- 用户角色编辑 → 已并入 DT-3（该条目做弹窗）。

## 4. 统一规范（弹窗交互）

- 弹窗宽度：`min(520px, 92vw)`；表单 `label-position="top"`；底部「取消 / 保存」；
- 危险操作二次确认保持（与现有弹窗一致）；
- 保存成功后 `ElMessage.success` + 刷新列表；失败提示不关闭弹窗；
- 移动端（≤760px）弹窗全宽（沿用现有 `.mobile-full` 约定）。

## 5. 验收

1. EK-1~EK-5（+可选 EK-6）全部为弹窗，页面无新增内联表单；
2. 各操作功能与改造前一致（黑名单/白名单/通知/代理保存均生效，刷新后可见）；
3. 设置项代理保存后 15 秒生效（沿用现有逻辑）；
4. 移动端窄屏弹窗全宽可用；
5. `npm test`（分段）+ `frontend:build` + `scan` 全绿；截图对照（改造前后）。
