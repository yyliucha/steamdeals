## 2. 通用骨架（BU/BV/BW 共用）

- 视口：`viewport-fit=cover` + `env(safe-area-inset-*)`，底部 Tab / 吸底操作条避开刘海与手势区；
- 触控：所有可点元素 ≥44×44px；输入框 ≥44px 高；
- 滚动：每页**单一滚动容器**（延续 Z 批"消除 vw/vh 逃逸"的教训，`main.css` 断点 1024/768/420 保留）；
- 桌面版网站兜底：保留现有 `desktopMode` 检测与提示，不删除；
- 性能：桌面大表格在移动端不渲染（`v-if` 切卡片）；列表首屏骨架屏；
- 兼容：微信内置浏览器（X5）、小米浏览器、iOS Safari 16+、Android Chrome；**不把 `beforeinstallprompt` 作为主路径**。

## 3. BU：移动端登录页重做（依赖 BT）

### 3.1 设计

- 全屏单列：品牌区 → 标题 → 模式切换（密码 / 邮箱验证码 / 忘记密码）→ 表单 → 主按钮；
- 输入框与主按钮 **48px 高**；主按钮在键盘弹出时**吸附底部**（`position: sticky` / 键盘避让），不再"点不到登录"；
- 图形验证码：图片 108×48、可点刷新；加载失败显示「验证码加载失败 点击重试」；输入框 `inputmode` 优化；
- 错误就地显示（沿用现有 `fieldError`），`reason=expired` 仍显示「登录已过期，请重新登录」；
- 已登录用户访问 `/login`：直接 `router.replace(next || '/')`；
- 底部：「下载安卓版 App」→ `/app`；「还没有账号？注册」；
- 页面不出现底部 Tab。

### 3.2 验收

1. 小米浏览器 / iPhone Safari / 微信内置 / Android Chrome：输入账号密码 → 登录成功 → 回到 `next` 或首页；
2. 键盘弹出时主按钮可见可点；验证码图可刷新、失败可重试；
3. 邮箱验证码 / 忘记密码两个模式同样可用；
4. 已登录访问 `/login` 直接回首页；带 `next=//evil.com` 时回落 `/`；
5. 桌面端登录页布局不变（≥1025px）。

## 4. BV：前台移动端重设计（底部 Tab）

### 4.1 路由与结构

| 路由（移动端） | 页面 | 说明 |
|---|---|---|
| `/` | `MobileHome`（新壳，`Home.vue` 在 `isMobile` 时渲染） | 底部 Tab 容器：首页 / 搜索 / 愿望单 / 我的 |
| `/game/:appid` | `MobileGameDetail`（新，全屏页） | 现有详情内容（指标/操作/报价/价格历史/DLC）+ 底部固定操作条；桌面访问时回落到首页并打开原弹窗 |
| `/search`、`/wishlist`、`/me` | Tab 内部视图（可复用同一壳的视图状态） | 切换 Tab 不压 history；从详情返回列表保留原滚动位置 |

- 详情/登录/注册/改密等子页**隐藏底部 Tab**；
- 桌面端（`!isMobile`）仍用现有 `Home.vue` 布局与 `el-dialog`，不改。

### 4.2 各页要点

- **首页**：顶部品牌 + 通知铃；单列大卡：封面 64×88、名称、平台/区服、价格（原价划线 + 折扣 + 史低徽标）、`购买 ↗`、`感兴趣`；筛选 chips（全部/折扣/史低/免费/未发售）；列表改**加载更多**（移动端不再用页码分页）；
- **搜索页**：搜索框自动聚焦、历史关键词（localStorage，最多 10 条）、结果复用首页卡片、空态/无结果提示；
- **愿望单页**：登录后展示本站愿望单（复用卡片 + 移除按钮）；未登录显示「登录后查看愿望单」+ 登录按钮（走 BT 的硬跳）；
- **我的**：当前账号（用户名/头像）、通知、主题切换、下载 App、修改密码、退出登录；未登录显示登录/注册；
- **详情页**（全屏）：封面、标题/英文名、三项指标、描述、操作（去 Steam 购买 / 愿望单 / 已拥有 / 感兴趣）、各区服与平台报价、价格历史、DLC 列表；底部固定操作条；返回列表保留滚动位置与筛选；
- **通知/公告**：抽屉保留，移动端全屏展示；登录页/注册页/改密页沿用 BU 风格。

### 4.3 验收

1. 四 Tab 切换正常、Tab 状态不写 history；从详情返回列表保留滚动位置与筛选；
2. 首页单列大卡显示完整价格/折扣/史低/购买/感兴趣；「加载更多」可用且与现有接口分页一致；
3. 搜索页历史/结果/空态正常；未登录点愿望单 Tab 直接进登录页（硬跳），登录后回愿望单；
4. 详情全屏页展示现有全部信息，底部操作条不遮挡内容；DLC 列表可翻页（BP 已发布口径）；
5. 微信内置浏览器可正常浏览、登录、打开详情；无横向滚动溢出；
6. 桌面端（≥1025px）首页/详情行为与现在一致。

## 5. BW：后台移动端重设计

### 5.1 结构

- `Console.vue`：顶部栏（☰ + 当前模块 + 通知）；☰ 打开**侧滑抽屉**，沿用现有 5 分组 13 模块；
- 内容区：模块标题 + 筛选条 + 卡片列表；桌面 ≥1025px 保持现有侧栏 + 表格；
- 模块清单（13 个，全部纳入）：游戏管理、回收站、站点通知、愿望单、访问记录、申诉管理、用户管理、Steam 账号、登录会话、邮件服务、操作日志、系统设置、数据统计。

### 5.2 卡片与操作

- 表格 → 卡片：每卡 2–4 行关键信息（主标识 + 状态标签 + 时间/备注）+ 右侧操作；保留筛选、排序、分页（每页 20）；
- 批量：复选框 + **吸底操作条**（已选 N + 执行），与现有 BulkBar/批量回执兼容；危险操作二次确认全宽弹窗；
- 表单/编辑：全屏抽屉（保存/取消吸附底部），替代现有宽弹窗；
- 数据统计/价格走势：单列图表或横向滚动，指标卡两列；
- 设置页：分组折叠 + 输入项全宽；
- 操作日志：日志行紧凑 + 点击展开详情。

### 5.3 验收

1. 手机（小米浏览器/Chrome）打开 `/console`：侧栏收进 ☰ 抽屉，5 分组 13 模块都能进入；
2. 每个模块的核心操作可在手机完成：查看/筛选/分页/编辑保存/批量执行（至少抽查游戏管理、访问记录、用户管理、系统设置、操作日志）；
3. 卡片信息与桌面表格一致（同一条记录字段对得上）；批量吸底条计数与执行回执正确；
4. 表单全屏抽屉可保存成功、取消不写库；危险操作有确认；
5. 桌面端 `/console` 布局与现在一致。

## 6. BX：首访下载 App 提示

- 触发：`/Android/i.test(UA)` 且非微信（`/MicroMessenger/i` 不匹配）且非 standalone、未记录过 `localStorage['sd:appPrompt']`；
- 展示：首页底部 Tab 上方一条「📱 安卓版 App 已上线 · 下载」，右侧 ×；
- 交互：点「下载」→ `/app`（并记录 `seen`）；点 × → 记录 `dismissed`，**永久不再弹**；每次安装/版本升级不重置（清缓存才恢复）；
- 微信 / iOS **不弹**（所有者决策：只安卓浏览器）；不依赖 `beforeinstallprompt`；现有 PWA「安装到桌面」条保留（Chrome）；
- 验收：小米浏览器首次访问出现一次，点关闭后不再出现，点下载进 `/app`；微信/iOS 不出现；TWA standalone 不出现；清 localStorage 后重新出现。
