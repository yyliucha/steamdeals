## 0. 背景与现状（2026-11-27 核实）

所有者反馈：封禁后页面不刷新只弹 toast；且「访问记录」四个 tab **整体也要重新设计**。

| tab | 现在装了什么 | 问题 |
|---|---|---|
| 访问明细 | 两个子视图（IP 统计 / 明细）+ 时间窗 + 状态筛选 + 展开详情 + 封禁/信任 | 与「异常审核」都在按 IP 看数据，口径不同 |
| 异常审核 | 按 IP 合并的待审列表 + 逐条规则 + 临时/永久封 + 信任/忽略 + 批量 | **真正的待办却埋在第二位**，无全局提醒 |
| 封禁与白名单 | 一个 tab 塞三个列表：黑名单 + 白名单 + 超频/临时封禁记录 | 滚动长、三套操作 |
| 设备 | 最近设备 100 条 + 设备封禁列表 + 批量 | 与异常审核「封设备」、封禁页「abuse」三处重复 |

**六个具体问题**：① 封 IP 三个入口（访问明细两子视图 + 异常审核 + 封禁页）、行为不一致（`banIp` 只刷 `loadSecurity()`，
不刷当前列表）；② 封设备三处；③ 三处都在看 IP；④ 封禁与白名单装三个列表；⑤ 没有概览；⑥ 待审无全局入口。

## 2. 信息架构（左导航 5 块）

| 块 | id | 内容 |
|---|---|---|
| **概览** | `overview` | 6 张数字卡 + 待审提醒；点「待审」跳异常处置 |
| **异常处置** | `review` | 按 IP 合并的待审队列（唯一处置入口）：临时封（10m/1h/1d）/ 永久封 / 信任 / 忽略 + 批量 |
| **访问分析** | `analysis` | IP 统计（默认）/ 明细子视图 + 时间窗 1/7/30 + 状态筛选（有效访问默认）+ 搜索 + 展开详情 + 行内快捷封禁/信任 |
| **封禁管理** | `ban` | IP 黑名单（解封 / 手动添加）、设备封禁（解封）、临时封禁记录（abuse：生效中/已过期/全部，解除≠移黑） |
| **白名单** | `whitelist` | 白名单列表（备注 / 限流配置 / 移出 / 添加） |

## 3. 关键交互

1. **封禁/信任后移出**：成功 → 乐观移除该行 → 重新拉取当前页补齐（当前页空了回上一页）→ toast 带「撤销」5 秒；
2. **撤销**：调 `DELETE /api/admin/blacklist/:ip`（信任的撤销调 `DELETE /api/admin/whitelist/:ip`），行回原位；
3. **计数联动**：概览的「待审 / 黑名单 / 白名单」数字同步减 1；
4. **状态口径**：`active`（有效访问，默认，排除 blacklisted + trusted）/ `normal` / `intercepted` / `banned`（临时封禁，保留）/ `blocked` / `trusted`；
5. **明细与统计同口径**；时间窗切换清空展开缓存。

## 4. 数据与接口

## 6. 安全与权限

- 权限不变（`requireAdmin`）；黑/白名单与封禁操作仍走既有接口与互斥口径（加黑移白 / 加白移黑+清临时封）；
- 「解除临时封禁」仍只动 `ip_abuse`，**不移除黑名单**（BJ 批决策不变）；
- 撤销入口只允许撤销本次操作（5 秒内），不提供「一键清空黑名单」这类危险批量。

## 7. 验收（8 条）

1. 左导航 5 块；URL `?view=` 可直达每块、浏览器后退可回；
2. 概览数字卡 6 项与接口一致；待审 > 0 标红、点击进异常处置；30 秒自动刷新（页面可见时）；
3. 异常处置：按 IP 合并、展开逐条规则、四种操作可用；批量封 IP/封设备/忽略可用；**处置后行消失且待审数减 1**；
4. 访问分析默认「有效访问」：已封禁 / 已信任 IP **不出现**；切「已封禁 / 已信任」可查历史；
5. 行内封禁/信任 → 确认 → 行消失 + toast「撤销」5 秒；点撤销后行回原位（黑名单/白名单已移除）；
6. 当前页最后一条被移除时自动回上一页；计数与分页同步；
7. 封禁管理三块（IP 黑名单 / 设备封禁 / 临时封禁记录）与白名单块功能完整；「解除临时封禁」不删黑名单；
