# 个人资料页精简（EZ，待开发，2026-11-23）

> 所有者要求（2026-11-23 修订）：个人资料页用 **Tab 切换**（不用原生按钮，全部用站内 Element Plus 组件）。
> demo：`docs/design/profile-tab-demo.html`（`?tab=basic|steam|prefs` 三个 tab）+ `profile-tab-demo-*.png`。

## 1. 现状

`frontend/src/pages/ProfilePage.vue`：5 个分区（基本信息 / Steam 绑定账号 / 偏好与通知 / 我的游戏库 / 我的统计）
全部堆在一页 + 底部保存。

## 2. 方案（Tab 版，所有者已确认可行）

**Web：3 个 Tab + 底部固定保存**
| Tab | 内容 |
|---|---|
| **基本信息** | 头像（更换/移除）+ 昵称 + 邮箱（已验证/更换）+ 用户名/角色（只读）+ 个人简介 |
| **Steam 账号** | 绑定管理 + 游戏库统计合并：每账号一行（名/SteamID/绑定时间 + 已拥有/愿望单/最近同步 + 查看已拥有/查看愿望单/设为默认/解绑）；底部「绑定新的 Steam 账号」 |
| **偏好与统计** | 主题 + 到价提醒邮件 + 本站愿望单/到价提醒/史低命中（3 数字） |

- Tab 用 `el-tabs`（与设置页一致），默认「基本信息」；
- 保存/取消**固定底部**（所有 Tab 共用同一表单状态，保存提交全部字段）；
- 未保存离开提示保持。

**手机端：Tab 横向滚动 + 底部固定保存**
- 顶部页头（个人资料 + 返回）+ Tab 条（横向可滚动）+ 单列卡片内容 + 底部固定「取消/保存修改」；
- 与 Web 同一 Tab 结构，内容单列（demo 右侧两屏）。

**按钮**：全部用 `el-button`（primary/secondary/danger/small），**禁止原生 button 默认样式**。

## 3. 功能不变

头像上传/移除、邮箱更换（验证码）、简介、绑定/解绑/默认账号、主题、邮件开关、统计、保存/取消、离开提示。

## 4. 验收

1. Web：3 Tab 切换正常（默认基本信息），内容与 demo 一致；保存/取消固定底部可用；
2. 手机端：Tab 横向滚动 + 底部固定保存，与 demo 一致；
3. 所有按钮为 Element Plus 组件样式（无原生默认按钮）；
4. 原功能全部可用；未保存离开提示保持；
5. `npm test`（分段）+ `frontend:build` + `scan` 全绿；截图对照（Web 三 Tab + 手机端）。
