# 个人资料页精简（EZ，待开发，2026-11-23）

> 所有者要求（2026-11-23）：个人资料页元素太多，适当合并（Web）；手机端出方案（demo 已给）。
> demo：`docs/design/profile-merged-demo.html` / `.png`（Web 合并版 + 手机端方案 + 切换账户菜单示例）。

## 1. 现状（代码证据）

`frontend/src/pages/ProfilePage.vue` 当前分区：基本信息 / Steam 绑定账号 / 偏好与通知 / 我的游戏库 /
我的统计 + 底部保存——**5 个分区**，信息重复（绑定账号与游戏库都按账号展示）与元素过多。

## 2. 合并方案（5 → 3 卡片）

| 新分区 | 合并内容 | 说明 |
|---|---|---|
| **① 基本信息** | 头像 + 昵称 + 邮箱 + 用户名/角色（只读）+ 简介 | 头像行紧凑；邮箱带「已验证/更换」 |
| **② Steam 账号** | 绑定管理 + 我的游戏库统计合并 | **每个账号一行**：名/SteamID/绑定时间 + 已拥有/愿望单/最近同步 + 查看已拥有/查看愿望单/设为默认/解绑；底部「绑定新的 Steam 账号」 |
| **③ 偏好与统计** | 主题 + 到价提醒邮件 + 本站愿望单/到价提醒/史低命中 | 3 个统计数字并排 |

- 保存按钮：**固定底部**（取消/保存修改）；
- 功能不变：头像上传/移除、邮箱更换（验证码）、简介、绑定/解绑/默认账号、主题、邮件开关、统计。

## 3. 手机端方案（demo 右侧）

- 单列卡片：头部紧凑（头像+昵称+邮箱+更换头像）、基本信息卡（昵称/简介）、Steam 账号卡（每账号：
  名/统计 + 2×2 按钮）、偏好与统计卡、**底部固定保存**；
- 断点沿用现有 `isMobile`（≤760px 或 UA）。

## 4. 验收

1. Web：3 卡片布局与 demo 一致；原功能全部可用（头像/邮箱/简介/绑定/解绑/默认/主题/邮件/统计）；
2. 手机端：单列 + 底部固定保存可用，与 demo 一致；
3. 保存/取消行为不变；未保存离开提示保持；
4. `npm test`（分段）+ `frontend:build` + `scan` 全绿；截图对照（Web/手机）。
