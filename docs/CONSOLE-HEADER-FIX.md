# 后台顶栏调整：去重「返回网站」+ 版本徽标普通用户可见（FB，待开发，2026-11-23）

> 所有者要求（2026-11-23）：个人资料页顶部不要再有「返回网站」（后台有两个），且恢复版本号显示。

## 1. 现状（代码证据）

| 元素 | 位置 | 现状 |
|---|---|---|
| 「返回网站 ↗」按钮 | `Console.vue:47`（`header-back`，`v-if="!isMobile"`） | 桌面端顶栏显示 |
| 「返回网站 ↗」菜单项 | `Console.vue:57`（用户下拉菜单，DT-5 加） | 菜单里也有 → **重复** |

## 2. 需求

1. **去重「返回网站」**：删除顶栏 `header-back` 按钮，**保留用户菜单里的「返回网站 ↗」**（一个入口）；
2. **版本徽标**：普通用户也显示当前版本号（如 `v2.28.5`）：
   - 普通用户：只读显示 `v{current}`（数据取 `/api/site` 的 `version` 字段，不触发管理员接口）；
   - 管理员：保持现状（可点击检查新版、显示「↑ 新版 vX 可用」）；
3. 版本徽标位置仍在顶栏右侧（用户菜单左侧），移动端保持隐藏或紧凑。

## 3. 验收

1. 桌面端后台任意页面：顶栏**只有一个**「返回网站」入口（用户菜单内）；
2. 普通用户顶栏显示 `v2.28.x`（当前版本号），不显示新版提示、不可点开管理员检查；
3. 管理员仍可点击检查、显示新版可用；
4. 移动端布局正常（无溢出）；
5. `npm test`（分段）+ `frontend:build` + `scan` 全绿；截图对照（普通用户/管理员）。
