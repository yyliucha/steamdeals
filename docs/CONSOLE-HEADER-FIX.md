# 后台顶栏调整：去重「返回网站」+ 版本徽标所有登录用户可见（FB，待开发，2026-11-23）

> 所有者要求（2026-11-23）：后台顶栏「返回网站」重复（两个），去掉一个；**普通用户也可以查看当前系统版本号、
> 也可以看到版本号更新**——`/api/admin/version` 不是管理员特供。

## 1. 现状（代码证据）

| 元素 | 位置 | 现状 |
|---|---|---|
| 「返回网站 ↗」按钮 | `Console.vue:47`（`header-back`，`v-if="!isMobile"`） | 桌面端顶栏显示 |
| 「返回网站 ↗」菜单项 | `Console.vue:57`（用户下拉菜单，DT-5 加） | 菜单里也有 → **重复** |
| 版本徽标 | `Console.vue:46`（`header-version`，`v-if="user?.role==='admin'"`） | **仅管理员可见**（前端限制） |
| 版本接口 | `src/routes/admin-settings.js:65` `GET /api/admin/version` | **`requireAdmin()`**（管理员专属）——普通用户 403 |

## 2. 需求

1. **去重「返回网站」**：删除顶栏 `header-back` 按钮，保留用户菜单里的「返回网站 ↗」（单一入口）；
2. **版本徽标：所有登录用户可见**（普通用户 + 管理员）：
   - 显示当前版本（`v2.28.x`）+ 有新版时显示「↑ 新版 vX 可用」；
   - 普通用户可见、可看到更新提示（不可强制刷新外网检查——`force=1` 仅管理员）；
3. **接口**：`GET /api/admin/version` 从 `requireAdmin()` 改为**登录用户可访问**（未登录仍 401）；
   - `force=1` 强制检查仅管理员（防普通用户频繁触发外网检查）；
   - 响应契约不变；
4. 移动端保持紧凑/隐藏。

## 3. 验收

1. 桌面端后台：只有一个「返回网站」入口（用户菜单内）；
2. **普通用户**顶栏显示 `v2.28.x`；有新版时显示「↑ 新版 vX 可用」；点击不触发强制外网检查（或只读）；
3. 管理员：可点击检查/强制刷新，行为不变；
4. 未登录调用版本接口仍 401；
5. `npm test`（分段）+ `frontend:build` + `scan` 全绿；普通用户/管理员截图对照。
